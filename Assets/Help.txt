GETTING STARTED

Run ReShade Centralized as administrator. In Setup, keep Documents\ReShade Centralized or choose a storage folder outside the app folder. Keep that folder available when playing.

1. Close your games. Choose Runtime & storage > Update ReShade.
2. Open Shader packages, check the packages you want, and choose Apply selection.
3. Choose Games > Install game and select the game's .exe. Use Check graphics API if unsure, then choose the API and build yourself. Standard is suitable unless you need add-ons. For Vulkan, follow the steps below first.
4. Review the changes and any replacement warning, then choose Install.
5. Launch the game. Press Home to open ReShade, choose effects, and save your preset.

CHOOSING AN API AND ADD-ONS

Match the game's graphics mode: DirectX 9, DXGI (DirectX 10/11/12), OpenGL, or Vulkan. Choose Vulkan for DXVK or RTX Remix.
For add-ons, choose Standard + add-on support. Select the game > Open profile and place its .addon32 or .addon64 files there, following the add-on author's instructions.

VULKAN GAMES

Vulkan support is shared between games. Its build is chosen under Runtime & storage, rather than separately for each game.

1. Close your Vulkan games and finish Update ReShade.
2. Under Runtime & storage > Vulkan - all games, choose a build and select Apply / repair.
3. Choose Games > Install game, select the executable, choose Vulkan, review the changes, and install.
4. Launch the game and press Home to configure ReShade.

- Already listed under Vulkan games: select an entry without (Managed) and choose Manage game. For a (Managed) entry, use Games > Repair / edit.
- Change the shared build: close your Vulkan games, choose the build under Runtime & storage, then Apply / repair. This affects Vulkan support installed by this app. Use the original installer to change support installed by another tool.
- Disabled or explicit layer warning: use that layer's installer to enable it. Apply / repair will not override it.
- Unregister keeps shared Vulkan support. Use Remove app-owned layers only when no games still need it. Keep it if unsure whether other games use it.

EVERYDAY ACTIONS

- Shader packages: check to add/update; uncheck installed packages to remove. Choose Apply selection or Update selected. Yellow marks additions; red marks removals. Removing a package also deletes custom files inside it. Required packages stay selected.
- Apply shader changes before leaving the tab, refreshing the catalog, or purging; unapplied selections reset. Use Refresh catalog to update the package list.
- Update ReShade: close affected games, then Runtime & storage > Update ReShade.
- Change a game's executable, API, or build: select it > Repair / edit. Use Repair all to repair all registered games.
- Yellow game warning: hover for details, then use Repair / edit.
- Find presets and settings: select a game > Open profile.
- Remove ReShade from a game: select it > Unregister. Profile files and local shaders are kept.
- Read credits and licenses: open Credits.

EXISTING INSTALLATIONS AND APP UPDATES

Back up custom files before approving replacements. Replaced files cannot be restored by Unregister. An existing selected preset is copied into the profile when available; the original is kept.
Keep central storage when updating or replacing the app. After reinstalling, choose the same storage folder in Setup to reopen your games and presets. If an older beta's storage is rejected, follow the error message.

IF SOMETHING DOES NOT WORK

- Still loading: wait until the controls unlock. Choose Retry if loading fails.
- Storage unavailable: reconnect its drive or return the folder to its original location, then Retry.
- ReShade does not appear: check the executable and API, run Update ReShade, then Repair / edit with the game closed. For Vulkan, also Apply / repair. Some games block ReShade.
- Download fails: check your connection and retry. You can download matching Standard and add-on installers from https://reshade.me and use Import downloaded installers. Select Standard first.
- Missing or modified shader files: back up custom files, then restore the package originals or use Purge shader folder followed by Apply selection. Purge deletes all central shaders and textures, including custom files.
- File conflict or access denied: close games and other ReShade installers, read the warning, and resolve the named files before retrying. Use Repair / edit for replacements that Repair all cannot approve.
- Other errors: check Activity. If the app closes unexpectedly, look for Crash.log beside the app.
- Exit: use X or Alt+F4. If closing stalls, close again to exit immediately. Use Windows End task if the window is completely frozen.
