GETTING STARTED

Run ReShade Centralized as administrator. Keep the default storage folder, Documents\ReShade Centralized, or choose a folder outside the app folder. Keep it at the same location and available when playing.
1. Choose Runtime & storage > Update ReShade.
2. In Shader packages, select packages and choose Update selected.
3. Choose Games > Install game. Select the actual game executable, not its launcher, and choose its graphics API and build. Review the changes, check the replacement confirmation if shown, then choose Install. Use the Vulkan steps below for Vulkan games.
4. Launch the game. Press Home to open ReShade's overlay unless you have changed its shortcut, then select effects and save a preset.

CHOOSING AN API AND BUILD

Match the API in the game's settings: DirectX 9, DXGI (DirectX 10/11/12), OpenGL, or Vulkan. Use Check graphics API for a recommendation if unsure.
Choose Standard unless you need add-ons. For add-ons, choose Standard + add-on support and put the add-on files in the game's Open profile folder: .addon32 for 32-bit games or .addon64 for 64-bit games. Include any files required by the add-on. An existing [ADDON] AddonPath in the profile's ReShade.ini takes precedence: remove it to use the profile folder, or set it to the game folder to load add-ons there instead.

INSTALLING FOR A VULKAN GAME

Close the game first and make sure Update ReShade has finished.
1. Open Runtime & storage. Under Vulkan - all games, choose Standard or Standard + add-on support, then choose Apply / repair.
2. Open Games > Install game and select the game executable.
3. Choose Vulkan. The build is set by the Vulkan choice above. Review the changes and choose Install.
4. Launch the game and use ReShade's overlay to select effects and save a preset.

If an existing game appears under Runtime & storage > Vulkan games without the (Managed) label, select it and choose Manage game instead, then review and confirm the setup. For games marked (Managed), use Games > Repair / edit.
To change the Vulkan build later, close your Vulkan games, change it under Runtime & storage and choose Apply / repair. This changes shared layers installed by this app. Layers from another installer keep their existing build; use that installer to change it.
Check the Vulkan status before launching. If it says an existing layer is disabled or explicit, use that layer's installer to enable it; Apply / repair will not override it.
Unregister removes this app's setup for the selected game. The shared Vulkan layer stays installed.
Vulkan games share the layer's registry entries; each game's ReShade.ini enables its own setup. A game does not need its own registry entry.
After unregistering all Vulkan games, Remove app-owned layers removes only registrations created by this app. It refuses removal while other games are recorded as using them. Other installers' registrations and runtime files are kept. Games not recorded in the application list may also share the layer, so keep it if unsure.

EVERYDAY USE

- Update ReShade: Runtime & storage > Update ReShade. Close affected games first.
- Shader packages: check packages to install or update; uncheck installed packages to remove them. Update selected applies the changes without another prompt. Removal also deletes custom files inside those packages. Required packages and dependencies of selected packages cannot be unchecked. Status shows what is currently installed; Incomplete means files are missing or cannot be verified. Refresh catalog updates the available package list.
- Reset shader packages: close affected games, choose Shader packages > Purge shader folder, then Update selected. This deletes all central shaders and textures, including custom files. Presets and game-local shaders are kept.
- Find presets and settings: select a game > Open profile.
- A yellow icon beside a game means its setup needs attention. Hover for details, then check the game folder or use Repair / edit.
- Change an executable, API, or build: select a game > Repair / edit. Use Repair all to repair all listed games.
- Remove this app's ReShade setup from a game: select it > Unregister. Presets, local shaders and files replaced by other tools are kept. Check Activity for files left behind.
- If a shader update fails or is cancelled, completed changes are kept. Check Activity, adjust the selection if needed, and retry Update selected.

EXISTING SHADERS AND PRESETS

Shaders and textures in reshade-shaders\Shaders and reshade-shaders\Textures beside the selected executable remain available. When registering a game that already has ReShade, its selected preset is copied into the profile if available; the original is kept. A missing preset uses a blank default. If the preset cannot be read, fix its access permissions or select another preset in the existing ReShade setup before retrying. Repairs keep your current profile preset.
Review any replacement warning before installing. Replaced files will be deleted; files that existing links point to are kept. Unregister will not recover deleted files.

UPDATING OR REINSTALLING THE APP

Close affected games before updating ReShade. Keep central storage when replacing or deleting the app folder. After reinstalling, select the same storage folder to reopen your games, shaders and presets.
If an older beta's storage cannot be opened, follow the message in the app. You may need to unregister games with the old version before setting up fresh storage.

COMMON PROBLEMS

- Check Activity for error details and file paths.
- Storage unavailable: reconnect its drive and restart the app, or select the correct folder when Setup appears. If you moved it, return it to its original location.
- Storage cannot be opened: choose another folder or restore your own backup. To reuse the default location, unregister affected games, delete Documents\ReShade Centralized and select it again in Setup. Deleting it loses its settings, presets and shaders.
- ReShade does not load: check the executable and API, run Update ReShade, then close the game and use Repair / edit. For Vulkan, also use Runtime & storage > Apply / repair. Some games block ReShade.
- Download fails: check your connection and retry. For runtimes, download matching standard and add-on-support installers from https://reshade.me and use Runtime & storage > Import downloaded installers. Select the standard installer first.
- Shader update reports changed, missing or unmanaged files: keep a copy of custom shaders, then restore the original package files or use Purge shader folder followed by Update selected. Purging resets all central shader packages, not just the failed one.
- Access denied or file in use: close games and other ReShade installers, run as administrator, check folder permissions, and retry.
- Existing installation or file conflict: check the path in the warning. Keep a copy of custom files before replacing or removing them, then retry.
- Repair all stops at a file conflict and makes no repairs. Use Repair / edit on the affected game to review any replacements, then retry Repair all.
- Duplicate effects: remove unused effect search paths in ReShade's overlay settings. Back up custom shaders before deleting an old reshade-shaders folder.
- Control disabled: select the relevant game or package and wait for any current operation to finish.
