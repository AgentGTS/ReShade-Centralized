GETTING STARTED

Run ReShade Centralized as administrator from a permanent folder. Choose a central storage folder, or import an existing ReShadeCentralized.ini. Keep central storage available when playing.
1. Choose Runtime & storage > Update ReShade.
2. In Shader packages, select packages and choose Install / update selected.
3. Choose Games > Install game. Select the actual game executable, not its launcher, then choose the graphics API and build.
4. Launch the game. Use ReShade's in-game overlay to select effects and save a preset.

CHOOSING AN API AND BUILD

Match the API in the game's settings: DirectX 9, DXGI (DirectX 10/11/12), OpenGL, or Vulkan. Use Check graphics API for a recommendation if unsure.
Choose Standard unless an add-on requires Standard + add-on support. Install add-ons manually.
Vulkan games share one build. Change it under Runtime & storage > Vulkan - all games, then choose Apply / repair.

EVERYDAY USE

- Update ReShade: Runtime & storage > Update ReShade. Close affected games first.
- Update shaders: Shader packages > Update installed packages. To add packages, use Install / update selected. Deselecting a package does not uninstall it.
- Find presets and settings: select a game > Open profile.
- Change an executable, API, or build: select a game > Repair / edit. Use Repair all to repair all listed games. Imported profiles need their executable selected before repair or relocation.
- Remove ReShade from a game: select it > Remove. Its profile and presets are kept.
- Adopt an existing Vulkan game: Runtime & storage > Vulkan games, select an unmanaged entry > Manage game.

MOVING, RESTORING, AND UPDATING THE APP

Close affected games before moving storage or restoring changes.
To move storage, use Runtime & storage > Relocate central folder and choose a separate, empty destination.
To undo changes, use Runtime & storage > Restore. Restoring an older operation also undoes newer operations.
When updating the app, keep ReShadeCentralized.json and Backups beside it, and retain central storage.

COMMON PROBLEMS

- Check Activity for error details and file paths.
- ReShade does not load: check the executable and API, install the runtime with Update ReShade, then close the game and use Repair / edit. For Vulkan, also try Apply / repair. Some games block ReShade.
- Download fails: check your connection and retry. For runtimes, download matching standard and add-on-support installers from https://reshade.me and use Runtime & storage > Import downloaded installers. Select the standard installer first.
- Access denied or file in use: close games and other ReShade installers, run as administrator, check folder permissions, and retry.
- Existing installation or file conflict: review the warning's file path before proceeding. Back up custom files before resolving conflicts, then retry.
- Duplicate effects: remove unused effect search paths in ReShade's overlay settings. Back up custom shaders before deleting an old reshade-shaders folder.
- Control disabled: select the relevant game or package and wait for any current operation to finish.
