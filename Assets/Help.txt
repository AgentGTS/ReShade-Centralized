Quick start

1. Run as administrator. Pick a central folder outside the app and keep it available while you play.
2. Close your games. In Runtime & storage, click Update ReShade. Then pick your shader packages and hit Apply selection.
3. In Games, choose Install game and pick the game's actual .exe. Check graphics API can suggest an option. Choose the API and build, review any replacements, then install.
4. Press Home in the game to open ReShade and save a preset.

Vulkan

The layer is shared. Close your Vulkan games, pick its build in Runtime & storage, and hit Apply / repair before installing a Vulkan game. If another installer set up a disabled or explicit layer, use that installer to enable it. Use Manage game for an untracked game in the Vulkan list.

Usage

- Repair / edit changes the executable, API, or build and fixes broken installs. Hover over a red or yellow warning for details. Yellow usually means your preset needs shaders you’re missing.
- Open profile takes you to presets and add-ons. Choose Standard + add-on support if your game needs add-ons.
- Save a copy of any custom files before approving replacements.
- Uncheck a shader package and apply to remove it, including custom files in that package. Purge shader folder also deletes custom central shaders and textures.
- Unregister removes verified links and the selected and default presets inside the profile. It keeps shared runtimes and external presets. Use Remove app-owned layers when no games need the shared Vulkan layer.

Problems

- ReShade missing? Check the .exe and API, update ReShade, then use Repair / edit. For Vulkan, try Apply / repair too.
- Runtime download failing? Get both installers from reshade.me and use Import downloaded installers. Pick Standard first.
- Storage offline? Reconnect the drive or restore the original path, then choose Retry. Choose folder... can open another valid store or start fresh in an empty folder.
- Check Activity for errors and any files the app kept. Close the game before retrying a file conflict. If the app crashes, look for Crash.log beside it.
