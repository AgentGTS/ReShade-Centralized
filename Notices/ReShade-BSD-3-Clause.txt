The manager's bootstrap resolution, translation-layer handling, compatibility
rule interpretation, and preset path handling reference the native ReShade
installer/runtime. The manager uses its own managed implementation. This notice
is retained for any adapted portions; it does not license separate catalogs or
third-party shader repositories. ReShade's authors do not endorse this project.
